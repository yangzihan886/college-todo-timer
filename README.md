# 大学待办清单 & 番茄专注计时器
## 项目介绍
这是面向大学生的简易工具，可以管理日常待办任务，附带番茄专注计时器。
任务会自动保存到本地`tasks.json`文件，关闭程序后再次打开不会丢失记录。
此项目用于wustLABA社团考核二

### 功能清单
1. 添加待办任务，可标记分类（学习/社团/生活）
2. 查看全部任务，区分已完成/未完成
3. 标记任务完成状态
4. 自定义时长番茄专注倒计时
5. 自动持久化保存任务数据

## 运行方法
1. 电脑安装Python环境
2. 在终端运行命令：
```bash
python todo_timer.py
